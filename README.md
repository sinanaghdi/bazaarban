# بازاربان — تحلیل فروش، مشتریان و عملکرد کسب‌وکارهای کوچک

بازاربان یک نمونه‌کار فارسی و RTL برای نشان‌دادن توانایی تحلیل داده است؛ نه یک سیستم حسابداری و نه مدرک تقاضای بازار. پروژه با Python و Pandas، کوئری SQL و داشبورد تحت وب بدون وابستگی به backend اجرا می‌شود.

> **دادهٔ فایل `data/demo/sales_synthetic.csv` کاملاً مصنوعی و قابل بازتولید است.** نام فروشگاه‌ها و کالاها نمونه‌اند؛ هیچ فروش، مشتری، سود یا اثر تجاری واقعی گزارش نمی‌شود.

## قابلیت‌ها

- generator قطعی با seed ثابت و manifest شامل تعداد ردیف و SHA-256؛
- دادهٔ مصنوعی با چند ناهنجاری کنترل‌شده برای تمرین ممیزی کیفیت؛
- پاک‌سازی نوع داده و تفکیک ردیف فروش مثبت و مقدار quantity منفی؛
- تعریف KPI با صورت، مخرج، grain و محدودیت؛
- تحلیل فروش، فاکتور، کالا، فروشگاه و مشتری تکراری؛
- SQL قابل اجرا در SQLite و خط لولهٔ Pandas؛
- داشبورد فارسی RTL با فیلتر تاریخ و فروشگاه؛
- تاریخ میلادی ISO در داده، تبدیل شمسی برای نمایش، مرتب‌سازی بر اساس تاریخ میلادی؛
- تست‌های محاسبات، تاریخ و کیفیت داده.

## راه‌اندازی در Windows / PowerShell

پیش‌نیاز: Python 3.11+ و PowerShell. نیاز به Node، PostgreSQL یا کلید سرویس خارجی نیست.

```powershell
# از ریشهٔ مخزن
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

# تولید مجدد دادهٔ مصنوعی ثابت
python scripts/generate_demo_data.py

# اجرای تست‌ها
python -m pytest -q

# اجرای تحلیل و تولید گزارش JSON
python scripts/run_analysis.py

# اجرای داشبورد از ریشهٔ مخزن (نه بازکردن مستقیم فایل HTML)
python -m http.server 8000
```

سپس `http://localhost:8000/dashboard/` را باز کنید. توقف سرور با `Ctrl+C` انجام می‌شود.

## بازتولید و ممیزی داده

- منبع، وضعیت مجوز، نوع داده، seed، تعداد ردیف و SHA-256 در `docs/dataset_manifest.json` هستند.
- پس از تغییر generator، فرمان `python scripts/generate_demo_data.py` را اجرا کنید تا CSV/JSON و manifest به‌روزرسانی شوند.
- خروجی CLI در `reports/generated_summary.json` ذخیره می‌شود.
- دستورات SQL در `sql/schema.sql` و `sql/analytics.sql` آمده‌اند. این SQL برای SQLite نوشته شده و در این مرحله ادعای اجرای PostgreSQL وجود ندارد.

## تعریف KPIها

فرمول و مخرج در `docs/kpi_dictionary.md` هستند. نکتهٔ اصلی: تعداد فاکتور با تعداد ردیف مساوی نیست؛ میانگین فاکتور از فروش خالص مثبت تقسیم بر تعداد فاکتورهای distinct واجدشرایط محاسبه می‌شود. ردیف برگشت از فروش مثبت جداست و مقدار منفی دوباره از جمع علامت‌دار کم نمی‌شود.

## ساختار پروژه

- `src/bazaarban/analytics.py`: ingestion، ممیزی و محاسبه؛
- `src/bazaarban/generator.py`: تولید دیتاست synthetic؛
- `src/bazaarban/calendar_fa.py`: تبدیل میلادی→شمسی برای نمایش؛
- `dashboard/`: رابط تعاملی فارسی؛
- `sql/`: مدل داده و کوئری؛
- `tests/`: تست‌های اجراشدنی؛
- `docs/`: manifest، Data Dictionary، KPI و روش‌شناسی؛
- `reports/`: گزارش مدیریتی و خروجی قابل بازتولید.

## تصویر داشبورد

- `screenshots/dashboard-static-preview.png` پیش‌نمایش تصویری ثابت از مقادیر واقعی خروجی همین دیتاست مصنوعی است.
- این فایل capture مرورگر تعاملی نیست؛ اجرای تعاملی dashboard با دستور `python -m http.server 8000` و مسیر `/dashboard/` انجام می‌شود.

## محدودیت‌ها

داده واقعی کسب‌وکار یا اجازهٔ مشتری وجود ندارد. مالیات، هزینهٔ خرید، سود، موجودی واقعی، تسویه و علت مرجوعی در داده نیستند. نمایش شمسی وابسته به پشتیبانی تقویم فارسی مرورگر است؛ مقدار ذخیره‌شده و مرتب‌سازی بر اساس تاریخ میلادی می‌ماند. برنامه authentication ندارد چون از backend یا دادهٔ واقعی استفاده نمی‌کند.

## گام‌های بعدی

اتصال به دادهٔ ناشناس مشتری فقط با مجوز کتبی، افزودن تست تطبیق SQL/Pandas، بررسی اختلاف locale عددی، snapshotهای مقایسه‌پذیر و تهیهٔ بازبینی مدیریتی مبتنی بر دادهٔ واقعی. هیچ‌کدام در این نسخه ادعای انجام‌شده ندارند.
