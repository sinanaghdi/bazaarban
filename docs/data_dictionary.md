# فرهنگ دادهٔ بازاربان

تمام داده‌های پوشهٔ data/demo مصنوعی و قابل بازتولید هستند؛ نام محصولات، فروشگاه‌ها و مشتریان ساختگی‌اند.

| ستون | تعریف | قاعده |
|---|---|---|
| sale_date | تاریخ میلادی YYYY-MM-DD | منبع فیلتر و مرتب‌سازی؛ شمسی فقط نمایشی است. |
| invoice_id | شناسهٔ فاکتور | واحد شمارش invoice؛ تعداد ردیف جایگزین تعداد فاکتور نیست. |
| store_id و store_name | شناسه و نام فروشگاه آزمایشی | مقایسهٔ فروشگاه‌ها. |
| product_code، product_name، category | مشخصات کالای آزمایشی | کد محصول از نام پایدارتر است. |
| customer_id | شناسهٔ ساختگی مشتری، گاهی خالی | هویت مشتری گمشده حدس زده نمی‌شود. |
| quantity | تعداد ثبت‌شده | مقدار منفی ردیف برگشت شبیه‌سازی‌شده است، نه رخداد واقعی. |
| unit_price_irr | قیمت واحد به ریال | مقدار منفی یا نامعتبر ردیف را از KPI کنار می‌گذارد. |
| discount_irr | تخفیف ردیف به ریال | غیرمنفی؛ برای quantity منفی باید صفر باشد. |
| line_gross_irr | quantity ضربدر unit_price_irr | علامت quantity حفظ می‌شود. |
| line_recorded_value_irr | مبلغ ناخالص منهای تخفیف | پروکسی ثبت‌شده است، نه الزاماً درآمد حسابداری. |

ستون‌های مشتق‌شده هنگام بارگذاری ساخته می‌شوند؛ CSV فقط داده‌های ورودی را نگه می‌دارد.
